# 2026-2 SNU DH 10 — MIMIC-III ICU mortality

Early-warning models that predict in-ICU death 24 hours ahead from hourly MIMIC-III vitals/labs.
The pipeline, results and documentation land through pull requests.

MIMIC-III is a credentialed PhysioNet resource: no patient data, derived tables or per-row predictions
are kept in this repository.
